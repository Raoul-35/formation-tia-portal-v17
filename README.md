# Formation TIA Portal V17 et WinCC Advanced

## Présentation

Formation pratique en automatisme industriel utilisant les logiciels Siemens TIA Portal V17 et WinCC Advanced.

Cette formation associe programmation des automates, supervision industrielle, simulation et gestion de projets avec Git et GitHub.

## Environnement technique

- TIA Portal V17
- STEP 7
- WinCC Advanced
- S7-PLCSIM
- WinCC Runtime Advanced
- Automate Siemens S7-1200
- Git et GitHub

## Objectifs pédagogiques

- Comprendre l'architecture des systèmes automatisés.
- Configurer les automates Siemens.
- Programmer en LAD, FBD et SCL.
- Traiter les signaux TOR et analogiques.
- Réaliser des séquences automatisées.
- Développer des interfaces de supervision.
- Configurer les alarmes et historiques.
- Simuler et diagnostiquer des installations industrielles.

## Programme

1. Fondamentaux de l'automatisme industriel
2. Découverte de TIA Portal V17
3. Configuration des automates S7-1200
4. Programmation LAD
5. Temporisateurs et compteurs
6. Blocs FC, FB et DB
7. Communication industrielle
8. WinCC Advanced
9. Alarmes et historiques
10. Simulation et diagnostic
11. Projets industriels

## Gestion du projet

Git et GitHub sont utilisés pour :
- Versionner les programmes.
- Documenter les exercices.
- Suivre les évolutions.
- Organiser les projets industriels.

## Auteur

Formation personnelle en automatisme industriel et supervision.
